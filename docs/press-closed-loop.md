# PRESS — closed-loop campaign intelligence

PRESS publish-gate work stays **deferred** in the runtime (see `MASTER.md`).
This note records the competitive posture so we do not resume PRESS as a
generator farm.

Adobe Firefly (20 Aug 2026) is aggregating image, video, music, speech, and
sound-effect models into one creative-production surface. Model aggregation is
table stakes. A MSTRMND content engine that only generates copy/image/video/voice
will be out-packaged.

Differentiation sits one level higher:

```text
business objective
  → audience
  → brand memory
  → campaign thesis
  → asset plan
  → generation          ← Firefly / GPT-Image-2 / peers as providers
  → evaluation
  → approvals           ← human gate remains a hard stop
  → distribution
  → performance
  → next campaign
```

Use Firefly (and GPT-Image-2 transparent assets) as execution providers where
useful. Compete on organizational intelligence and the closed loop, not on
creative-tooling breadth.

GPT-Image-2 `background: "transparent"` belongs on the creative-provider
benchmark (cutouts, avatars, app assets, overlays, presentation graphics,
brand-template composites). It is not the default until a **live** eval beats
background-removal post-processing on halo, consistency, and cost.
