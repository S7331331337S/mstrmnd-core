# Research Protocol

1. **Frame** — restate the question and list the specific claims that must be
   true for a confident answer.
2. **Gather** — collect evidence for each claim. Prefer primary and recent
   sources. Note where evidence is thin.
3. **Synthesize** — write a short brief: what is established, what is
   contested, what is unknown.
4. **Record** — write the durable conclusions to the Third-Mind
   (`memory_write`) with clear keys and tags so the alliance reuses them.
5. **Report** — end with a Confidence rating (high / medium / low) and the one
   open question that most affects the decision.
